# 🛡️ Job Shield — AI & Web3-Powered Scam-Free Job Portal

Job Shield is a modern full-stack job platform that protects users from fake job listings using AI-based scam detection and blockchain-based recruiter verification (via NFT badges). Built with Next.js App Router, Tailwind CSS, and future-ready integrations with AI and Polygon blockchain, it's designed to be secure, smart, and scalable.

## 🧠 Features

### ✅ AI-Based Fake Job Detection  
- Scans job descriptions for scam indicators using NLP and ML.
- Flags suspicious posts before they reach users.

### ✅ Blockchain Recruiter Verification (NFT Badge)
- Recruiters complete KYC → NFT badge minted on Polygon.
- Verified recruiters get a badge visible on job listings.

### ✅ TrustScore System
- Recruiters earn a dynamic TrustScore based on history, verification, and user feedback.
- Job seekers filter listings based on TrustScore.

### ✅ Role-Based Access
- Recruiters: Post jobs, view applications, manage badges.
- Job Seekers: Browse & apply to jobs, track applications.
- Admin: Verify KYC, handle scam reports.

### ✅ Bonus Features
- Real-time notifications (status updates)
- Dark/light mode toggle
- AI-powered job recommendations (chatbot - coming soon)
